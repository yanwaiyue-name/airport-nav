新手避坑指南

  1. 先看状态再点链接：❌ 失效的别浪费时间；❓ 未验证不一定是死链，去来源仓库找最新入口。
  2. 域名被封 ≠ 跑路：先去机场的官方地址发布页 / GitHub 仓库 / 官方群找新域名。
  3. 先月付，再年付：月付验证一个月稳定性后再考虑长周期。
  4. 超低价年付当「备用玩具」：不要把重要流量全押在上面。
  5. 跑路前兆：长期不发公告、官方群解散或禁言、支付通道频繁更换、突然大幅清仓促销——占两条以上就该准备备用方案。
  6. 多方评测交叉验证：很多推荐仓库带邀请返利，单一来源的好评要打折。
  7. 支付方式：支持支付宝/微信、有工单系统的相对靠谱；只收虚拟币的要多留心眼。
  8. 特殊时期入口更易被封：提前备好至少两个机场。
  9. 隐私常识：机场能看到连接元数据，敏感账号登录尽量不走小机场节点。
  10. 数据每周六自动更新：看到「最后验证」日期太老的，谨慎对待。
